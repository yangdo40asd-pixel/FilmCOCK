FilmCOCK! 영화 상세 화면 이미지 기반 배치 체크리스트
====================================================

문서 목적
---------
첨부된 모바일 영화 상세 화면 이미지를 기준으로, 각 UI가 어디에 배치되어야 하는지 추론하고 구현 전후를 점검한다.
이 문서는 화면 배치와 사용자 행동의 기준 문서다.

판단 기준
---------
[x] 모바일 세로 화면 기준으로 우선 설계한다.
[x] 이미지가 화면의 첫 인상을 만들고, 정보는 이미지 아래에서 순차적으로 읽힌다.
[x] 주요 행동은 사용자가 영화를 본 직후 자연스럽게 찾을 수 있어야 한다.
[x] 긴 영화 제목·장르·줄거리·출연진에서도 겹침과 overflow가 없어야 한다.
[x] API 로딩·빈 데이터·오류가 레이아웃을 밀어내지 않아야 한다.
[ ] 첨부 이미지는 목표 레이아웃 참고용이며 실제 데이터가 없는 영역은 명확한 상태를 보여준다.

1. 화면 전체 계층
------------------
[ ] 화면은 세로 스크롤 가능한 영화 상세 페이지다.
[ ] 첫 영역은 영화 배경 이미지와 예고편 행동 영역이다.
[ ] 두 번째 영역은 영화 핵심 정보다.
[ ] 세 번째 영역은 시청 경로와 사용자 액션이다.
[ ] 네 번째 영역은 줄거리다.
[ ] 다섯 번째 영역은 주요 출연진이다.
[ ] 마지막 영역은 추천 영화다.
[ ] 하단 시스템 내비게이션 영역을 침범하지 않는다.
[ ] 모든 영역은 하나의 화면 안에서 카드가 카드 안에 중첩되지 않도록 구성한다.

2. 상단 영화 이미지 영역
------------------------
[ ] 배경 이미지는 화면 너비를 모두 사용한다.
[ ] 모바일 기준 높이는 약 300~360px 범위에서 검토한다.
[ ] 이미지 비율이 달라도 BoxFit.cover로 영역을 유지한다.
[ ] 이미지 아래쪽은 어두운 오버레이를 적용해 제목·버튼과 대비를 만든다.
[ ] 이미지 로딩 중 고정 높이 placeholder를 표시한다.
[ ] 이미지 로딩 실패 시 회색 또는 어두운 placeholder를 표시한다.
[ ] 이미지 위 왼쪽에 뒤로가기 버튼을 배치한다.
[ ] 뒤로가기 버튼은 상태바와 겹치지 않도록 SafeArea 기준으로 배치한다.
[ ] 예고편이 있는 영화만 중앙 재생 버튼을 표시한다.
[ ] 예고편 재생 버튼은 흰색 원형 버튼으로 이미지 위에 배치한다.
[ ] 예고편이 없으면 빈 버튼 공간을 남기지 않는다.
[ ] 재생 버튼과 뒤로가기 버튼의 터치 영역은 충분히 확보한다.

3. 영화 핵심 정보 영역
----------------------
[ ] 배경은 이미지 영역과 이어지는 어두운 상세 배경이다.
[ ] 좌우 기본 여백은 모바일에서 약 24~32px로 검토한다.
[ ] 영화 제목은 날짜보다 먼저 표시한다.
[ ] 긴 제목은 2줄까지 허용하고 화면 밖으로 넘기지 않는다.
[ ] 제목은 화면의 가장 큰 정보 텍스트 중 하나로 표시한다.
[ ] 개봉일은 `YYYY. MM. DD` 또는 안전한 한국어 날짜 형식으로 표시한다.
[ ] 개봉일이 없으면 빈 문자열 대신 `개봉일 정보 없음`을 표시한다.
[ ] 평점은 개봉일 옆에 배치한다.
[ ] 평점은 별 아이콘과 숫자를 함께 표시한다.
[ ] 평점이 없거나 0이면 잘못된 별점처럼 보이지 않게 처리한다.
[ ] 장르 목록은 평점 아래에 Wrap 형태로 배치한다.
[ ] 장르가 많으면 다음 줄로 자연스럽게 내려간다.
[ ] 장르 Chip의 고정 폭 때문에 화면이 넘치지 않는다.
[ ] 장르 텍스트가 길어도 Chip 내부에서 잘리지 않는다.

4. 보러가기 버튼 영역
---------------------
[x] 보러가기 버튼은 장르 목록 다음에 배치한다.
[x] 줄거리보다 먼저 배치한다.
[x] 버튼은 모바일 화면의 대부분 폭을 사용한다.
[x] 버튼 높이는 손가락 터치에 충분한 크기로 유지한다.
[x] 첨부 이미지처럼 보라색 계열을 주요 강조색으로 사용한다.
[x] 버튼 문구는 `보러가기`로 통일한다.
[x] 버튼에는 재생 또는 외부 이동 의미의 아이콘을 함께 표시한다.
[x] 버튼 터치 시 영화 ID와 영화 제목을 시청 경로 화면에 전달한다.
[ ] 상세 API가 실패해도 전달받은 영화 ID로 버튼을 사용할 수 있는지 확인한다.
[ ] 버튼을 누를 때 중복 Bottom Sheet가 여러 개 열리지 않게 한다.

5. 사용자 액션 영역
-------------------
[x] 보러가기 버튼 아래에 좋아요·봤어요·댓글·공유 영역을 배치한다.
[x] 네 개 액션은 가로 한 줄에서 균등하게 정렬한다.
[x] 아이콘은 텍스트보다 먼저 보여 행동 의미를 빠르게 전달한다.
[x] 선택 전 아이콘은 흰색 또는 회색 계열로 표시한다.
[x] 좋아요 선택 시 선택 상태 색상을 변경한다.
[x] 봤어요 선택 시 선택 상태 색상을 변경한다.
[x] 댓글 선택 시 안내 상태로 이동한다.
[ ] 공유 선택 시 OS 공유 시트를 호출한다. 현재는 영화 링크 복사로 동작한다.
[ ] 로그인 전 사용자와 로그인 후 사용자의 저장 정책을 구분한다.
[ ] 액션 영역은 줄거리 제목과 겹치지 않는다.
[ ] 작은 화면에서 네 개 아이콘이 잘리지 않는다.

6. 시청 경로 Bottom Sheet
-------------------------
[x] 보러가기 버튼을 누르면 하단에서 Bottom Sheet가 올라온다.
[x] 배경은 상세 화면 위에 반투명 scrim을 표시한다.
[x] Bottom Sheet 상단 모서리는 둥글게 처리한다.
[x] 상단 중앙에 드래그 핸들을 표시한다.
[x] 제목은 `어디서 볼까요?`로 표시한다.
[x] 제목은 시트 상단 중앙에 배치한다.
[x] `OTT`와 `극장` 탭을 제목 아래에 배치한다.
[x] OTT 탭을 기본 선택 상태로 연다.
[x] 선택 탭은 보라색 indicator를 사용한다.
[x] 미선택 탭은 낮은 대비의 회색을 사용한다.
[x] 시트 높이는 화면의 약 70%를 넘지 않도록 제한한다.
[x] 콘텐츠가 많을 때 시트 내부만 스크롤한다.
[x] 시트를 아래로 밀거나 바깥 영역을 눌러 닫을 수 있다.

7. OTT 탭 내부
--------------
[ ] TMDB Watch Providers API를 사용한다.
[ ] 국가 코드는 대한민국 `KR`로 고정한다.
[ ] 구독·무료·광고·대여·구매 데이터를 파싱한다.
[ ] 서비스 아이콘은 고정 크기로 표시한다.
[ ] 아이콘 아래에 서비스명을 표시한다.
[ ] 서비스명 아래에 이용 방식 라벨을 표시한다.
[ ] 같은 서비스가 여러 이용 방식으로 중복될 경우 표시 정책을 정한다.
[ ] 로고가 없으면 TV 아이콘 placeholder를 표시한다.
[ ] 로고 네트워크 실패 시 레이아웃을 유지한다.
[ ] 서비스가 많으면 3열 그리드 또는 내부 스크롤로 표시한다.
[ ] API 로딩 중에는 중앙 로딩 표시를 보여준다.
[ ] API 오류에는 다시 시도 버튼을 보여준다.
[ ] 국내 서비스가 없으면 빈 상태 문구를 보여준다.
[ ] OTT 서비스 선택 시 해당 링크를 외부 앱 또는 브라우저로 연다.
[ ] 링크가 없거나 열리지 않으면 사용자에게 안내한다.
[ ] TMDB 공통 링크와 각 플랫폼 직접 링크의 차이를 문서화한다.

8. 극장 탭 내부
----------------
[ ] 극장 탭은 영화 관람 예약 행동을 위한 영역이다.
[ ] CGV를 표시한다.
[ ] 롯데시네마를 표시한다.
[ ] 메가박스를 표시한다.
[ ] 현재 영화 제목을 URL 인코딩해 극장사 검색 링크에 전달한다.
[ ] 링크 선택 시 각 극장사의 영화 검색 화면으로 이동한다.
[ ] 검색 화면에서 해당 영화 확인 후 예매할 수 있어야 한다.
[ ] 극장사별 영화 ID를 확보하면 검색 링크를 상세·예매 딥링크로 교체한다.
[ ] 실제 상영 여부 데이터가 없으면 무조건 상영 중이라고 표현하지 않는다.
[ ] 예매 가능 여부는 극장사 페이지의 최신 상태를 기준으로 한다.
[ ] 각 극장 항목에 `영화 검색 후 예매하기` 안내를 표시한다.
[ ] 극장 사이트가 열리지 않으면 실패 안내를 표시한다.
[ ] 공식 사이트 URL이 바뀌면 링크 백테스트를 다시 한다.

9. 줄거리 영역
--------------
[ ] 사용자 액션 영역 다음에 줄거리 제목을 표시한다.
[ ] 줄거리 본문은 충분한 줄 간격을 둔다.
[ ] 긴 줄거리는 전체 세로 스크롤로 읽을 수 있어야 한다.
[ ] 줄거리 데이터가 없으면 `줄거리 정보가 없습니다.`를 표시한다.
[ ] 글자색은 배경과 충분한 대비를 갖는다.
[ ] 줄거리 본문이 버튼이나 출연진과 겹치지 않는다.
[ ] 번역되지 않은 비정상 원문 처리 정책을 영화에도 적용할지 검토한다.

10. 주요 출연진 영역
--------------------
[ ] 줄거리 아래에 `주요 출연진` 제목을 표시한다.
[ ] 출연진은 가로 스크롤 리스트로 표시한다.
[ ] 프로필 이미지는 원형으로 표시한다.
[ ] 이미지가 없으면 인물 아이콘 placeholder를 표시한다.
[ ] 이름은 이미지 아래에 표시한다.
[ ] 이름은 한 줄 말줄임표를 사용한다.
[ ] TMDB 한국어 표시명은 `displayName`을 사용한다.
[ ] 일본어·중국어·아랍어 등 화면 제외 원문은 표시하지 않는다.
[ ] 출연진 카드 선택 시 인물 상세 화면으로 이동한다.
[ ] 출연진 API 오류 시 상세 화면 전체가 깨지지 않는다.
[ ] 출연진이 없으면 안내 문구를 표시한다.

11. 추천 영화 영역
-------------------
[ ] 출연진 영역 아래에 추천 영화 영역을 배치한다.
[ ] 제목은 `이런 영화는 어떠세요?` 형태로 표시한다.
[ ] 추천 영화는 가로 스크롤 카드로 표시한다.
[ ] 포스터 비율을 일정하게 유지한다.
[ ] 영화 제목은 포스터 아래에 표시한다.
[ ] 긴 제목은 말줄임표 처리한다.
[ ] 추천 영화 선택 시 새 영화 상세 화면으로 이동한다.
[ ] 새 상세 화면에서도 보러가기 버튼이 동일하게 동작한다.
[ ] 추천 API 오류 시 빈 영역 또는 안내 문구를 표시한다.

12. 홈에서 상세 진입
---------------------
[ ] Hero Carousel 영화 선택 시 상세 화면으로 이동한다.
[ ] 홈 가로 영화 카드 선택 시 상세 화면으로 이동한다.
[ ] 목록 보기 영화 선택 시 상세 화면으로 이동한다.
[ ] 추천 영화 선택 시 상세 화면으로 이동한다.
[ ] 어떤 진입 경로에서도 영화 ID가 유지된다.
[ ] 어떤 진입 경로에서도 배경·상세·예고편·시청 정보가 동일하게 로드된다.
[ ] 뒤로가기 후 홈의 스크롤 위치가 불필요하게 초기화되지 않는지 확인한다.

13. 반응형·실기기 검수
----------------------
[ ] 360px 폭 Android 기기에서 제목이 넘치지 않는다.
[ ] 360px 폭에서 장르 Chip이 화면 밖으로 나가지 않는다.
[ ] 360px 폭에서 보러가기 버튼이 좌우 여백 안에 들어온다.
[ ] 360px 폭에서 네 개 액션 아이콘이 겹치지 않는다.
[ ] Bottom Sheet가 시스템 내비게이션 바를 가리지 않는다.
[ ] 긴 한국어 영화 제목을 테스트한다.
[ ] 장르가 5개 이상인 영화를 테스트한다.
[ ] OTT 서비스가 1개인 경우를 테스트한다.
[ ] OTT 서비스가 6개 이상인 경우를 테스트한다.
[ ] OTT 서비스가 없는 경우를 테스트한다.
[ ] 극장 링크가 열리지 않는 경우를 테스트한다.
[ ] 이미지가 없는 영화·인물을 테스트한다.
[ ] 네트워크를 끊은 상태에서 상세 화면을 테스트한다.
[ ] 화면 회전 또는 큰 화면에서 레이아웃을 확인한다.

14. 구현 완료 기준
------------------
[ ] 이미지의 정보 순서와 실제 화면의 정보 순서가 일치한다.
[ ] 영화 상세에서 보러가기 버튼을 찾기 쉽다.
[ ] 보러가기 버튼이 OTT·극장 선택 화면을 연다.
[ ] OTT 서비스 링크가 외부 앱 또는 브라우저로 열린다.
[ ] 극장 탭에서 영화 검색·예약 흐름으로 이동한다.
[ ] 좋아요·봤어요·댓글·공유의 구현 상태가 사용자에게 혼동을 주지 않는다.
[ ] 로딩·빈 상태·오류 상태가 모두 화면에 정의되어 있다.
[ ] 모든 긴 텍스트와 다수 콘텐츠가 화면을 깨뜨리지 않는다.
[ ] 홈·검색·목록·추천에서 진입한 상세 화면이 동일하게 동작한다.
[ ] 정적 분석과 실기기 순차 테스트를 완료한다.
