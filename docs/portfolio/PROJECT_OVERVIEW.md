# FilmCOCK 프로젝트 개요

갱신일: 2026-11-18 · 상태: 코드와 원격 README 기준 / 개발 기간 확인 필요

## 해결하려는 문제

영화 탐색·취향 추천·개인 활동 기록이 분리돼 있는 사용 흐름을 하나의 앱으로 연결한다.

## 구현 범위

Flutter 화면에서 TMDB·KOFIC 영화 및 인물 정보를 탐색하고 MBTI·장르로 추천한다. 좋아요·관람·댓글·프로필은 로컬에 기록한다. Firebase 인증과 Firebase AI Logic을 사용하며 질문 칩 규칙과 LLM 실패 대체 흐름을 함께 제공한다.

## 기술적으로 설명할 수 있는 내용

- 검색 지연 입력과 최신 응답 보호
- 홈 사전 준비·섹션별 실패·정상 데이터 캐시 복구
- 활동 저장 후 변경 신호와 마이페이지 재조회
- 공통 MBTI·장르 조건과 영화 ID 중복 제외
- LLM 계획 검증과 TMDB 후보 확인, 규칙 기반 대체
- 기능별 구조로 이행하며 저장 형식을 보존하는 방법

## 제출 전에 채울 사실

원격 README의 105972a 커밋에 기록된 기준으로 2인 팀 프로젝트이며, 본인은 팀장·시작/홈/검색/취향/주요 UI·데이터 연동·발표 자료를 담당했다. AI 영화 도슨트 챗봇의 핵심 구현은 팀원이 담당한 것으로 구분한다. 개발 기간, 이미지·데이터 사용 조건과 최신 검증 환경은 확인 필요로 남긴다. 커밋 수를 기여율로 바꾸거나 실행하지 않은 성능 수치를 적지 않는다.
