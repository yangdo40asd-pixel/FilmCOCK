# 포트폴리오 시연 안내

갱신일: 2026-11-17 · 상태: 시연 준비안 / 최신 캡처 대기

## 준비

개발 설정과 키 메모를 따라 사용자 환경에서 빌드한다. 개인 계정·실제 키·개인 댓글이 없는 시연 데이터를 사용한다. 정상 네트워크와 오류 복구 시나리오는 구분한다.

## 권장 순서

1. 시작 화면의 데이터 준비와 로그인·비회원 경로
2. MBTI·장르 선택 후 홈의 MBTI 전용 제목과 추천
3. 검색 자동완성·결과·영화 및 인물 상세
4. 좋아요·봤어요·댓글 작성 후 마이페이지·캘린더 확인
5. 질문 칩·자유 입력 추천, LLM 대체 흐름과 대화 초기화
6. 취향 재설정과 홈·취향·챗봇의 공통 조건
7. 설계도·공용 계약·저장 실패 처리·검증 소스로 기술 설명

## 캡처 관리

최신 검증 커밋·기기·날짜를 적은 화면만 docs/media/screenshots에 선별한다. 현재는 사용자 실행·촬영을 하지 않아 해당 폴더에 최신 대표 화면을 만들지 않았다. references/design의 과거 캡처는 디자인 이력이며 현재 동작 증거가 아니다.

실패·캐시·AI 설명의 한계도 함께 제시한다. 비밀정보·권리 미확인 이미지를 공개 시연 자료에 무단 포함하지 않는다.
