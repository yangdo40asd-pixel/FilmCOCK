# 알려진 한계와 확인 필요 사항

갱신일: 2026-11-17 · 상태: 현재 코드 조사 기준

- Firebase 인증은 사용하지만 취향·활동·프로필을 서버 DB로 동기화하지 않는다.
- MBTI·장르는 소유자별 키이고 활동·프로필·달력은 기기 공용 키다. 로그아웃 정리는 모든 사용자 범위 키를 제거할 수 있다.
- 추천 장르 집합은 최대 3개로 제한한다. 선택 장르 수에 따라 MBTI 장르가 뒤에서 제외될 수 있다.
- API 한 요청의 시간 제한이 앱 전체 시작 시간의 상한을 의미하지 않는다.
- LLM 후보를 TMDB로 확인하더라도 추천 적절성·설명 정확성을 완전히 보장하지 않는다.
- App Check는 현재 의존성에 포함되지 않는다. 서버 설정·요청 보호·할당량 상태는 이번에 확인하지 않았다.
- Android release는 현재 debug 서명을 사용한다.
- iOS·웹·데스크톱 실행은 이번 작업에서 검증하지 않았다. dart:io 직접 사용 지점도 있어 플랫폼 폴더 존재와 실행 지원을 구분해야 한다.
- 기존 챗봇 테스트는 가짜 조회 구현과 소유자별 키로 정리했고 경계 검사 소스를 추가했다. 이번 변경분은 아직 실행 검증하지 않았다.
- 루트 FilmCOCK!는 독립 저장소 이력을 보존한 submodule이다. 누락됐던 .gitmodules를 추가했으며 앱 실행에 필요하지 않은 과거 저장소다. 외부 원격 접근·새 복제는 아직 실행 검증하지 않았다.
- 일부 화면 사이의 직접 화면 이동과 정적 외부 API 구현은 남아 있다. 조회 계약을 주입할 수 있게 했지만 완전한 의존성 역전 이행으로 표현하지 않는다.
- 정적 인물 데이터 생성 원본, 이미지 권리, 기존 키 폐기·재발급 여부는 확인 필요다.

최신 실제 장애·검증 결과가 들어오면 코드 조사상 위험과 재현된 결함을 구분해 갱신한다.
