# 사용자 흐름

갱신일: 2026-11-17 · 상태: 코드 보존 기준 / 실동작 확인 대기

## 시작

Flutter 바인딩·키·테마 → Firebase·디스크 캐시 준비 → 스플래시와 홈 API 준비 → 인증·온보딩 판정 → 로그인 / MBTI / 장르 / 홈.

미인증 콜드 스타트는 기존 비회원 세션을 종료하고 로그인 화면으로 간다. 비회원 버튼으로 새 세션을 만든다. 인증된 동일 계정의 온보딩 완료 상태는 유지한다.

## 취향 변경

MBTI·장르 확정 → 소유자별 저장 → 두 결정 상태 확정 → 취향 변경 신호 → 홈·취향 재조회. 홈 개인화가 준비되는 동안 이전 영화 목록을 유지한다.

## 활동

상세 화면 입력 → ActivityRepository 직렬 쓰기 → 목록·개별 플래그·해당 날짜 캘린더 조정 → 성공 알림 → 마이페이지 최신 데이터 재조회.

저장 중 실패하면 기존 저장값 복원을 시도하고 화면 선택을 되돌린다. 연속 댓글 추가는 저장소에서 순서대로 처리한다. 계정별 활동 데이터 소유 범위 자체는 이번에 변경하지 않았다.

## 검색과 대화

검색 자동완성은 입력 지연과 요청 번호로 최신 결과를 우선한다. SearchResultsController는 결과 중복 제거·추가 페이지·오래된 결과 무시를 담당한다.

대화 초기화는 이전 요청 결과를 새 목록에 추가하지 않는다. 상세·예고편·외부 시청 경로 이동은 기존 화면 구성을 유지한다.
