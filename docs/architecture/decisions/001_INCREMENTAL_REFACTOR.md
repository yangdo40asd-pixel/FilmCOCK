# ADR 001 — 동작을 보존하는 점진적 기능별 분리

갱신일: 2026-11-17 · 상태: 채택

## 배경

화면 파일과 정적 서비스가 커져 UI, 요청 수명, 저장 정책을 함께 수정해야 한다. 코드와 디자인 참고 자료도 루트에 혼재한다.

## 선택

먼저 문서와 참고 자료를 분류하고, app 초기화·공용 계약을 분리한 뒤 기능별로 옮긴다. 기존 진입점은 필요할 때 호환 어댑터로 유지하며 참조가 사라졌을 때만 제거한다.

## 대안과 이유

- 전체를 한 번에 재작성: 기존 동작·저장 데이터의 회귀 범위가 커 제외한다.
- 상태관리 패키지 전체 교체: 구조 정리와 상태 동작 변경을 구분하기 어려워 별도로 미룬다.
- 기존 계층 폴더 유지: 이동량은 적지만 기능별 탐색과 포트폴리오 설명에 불리하다.

## 결과와 제약

중간 단계에는 기존 경로와 새 경로가 함께 있을 수 있다. 진행표에 미완료 경계를 남긴다. 런타임 검증 권한은 기존 사용자 규칙을 유지하며 코드 작성 완료를 실동작 통과로 표현하지 않는다.
